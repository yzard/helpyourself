# 第一批后端实现与验证

历史记录：保留当时的实现和测试事实；当前数据库策略、原件布局、HealthKit 范围及验证结果以 [2026-10-01 审查](../reviews/2026-10-01-raw-archive-and-skills-audit.md) 为准。

日期：2026-09-06。**历史记录：以下只描述最初 25 项测试的基础版本，已被后续实现扩展。当前状态以 [本轮验收](phase-a-results.md) 为准。**

## 已实现

- Rust/Axum 应用工厂、显式 TOML 加载及校验、相对路径解析、配置模板、HTTP 运行及优雅停止。
- SQLite schema v1、用户/会话/登录窗口/原文件/任务表；Argon2 密码、随机会话与摘要存储、管理员建号/重置/禁用。
- 会话鉴权及逐用户文件/任务访问；密码更改使旧会话及进行中的旧凭据登录失效。
- PDF/PNG/JPEG 流式上传、真实格式验证、限额、摘要、幂等重放、鉴权下载；保存文件与提交任务的恢复处理。
- 任务持久化、内部领取/续租/过期回收/完成与失败重试机制。尚无实际提取执行器，上传任务停在明确 blocked 状态。
- Docker 多阶段镜像、Compose、Caddy、非 root 应用进程、配置与数据挂载。

## 验证证据

- 25 项自动测试全部通过：配置、管理员命令、登录、隔离、数据库归属约束、会话摘要存储、版本迁移拒绝、文件解析、并发上传重放、限额、重启保留、任务租约及孤立文件清理。
- cargo clippy 的所有目标以 warnings-as-errors 通过；格式检查通过。
- Docker release 镜像构建成功；Compose 配置与脚本语法检查通过。
- 使用独立测试项目、临时卷和随机 loopback 端口启动 Compose；以 Caddy 本地 CA 验证 HTTPS，完成后端登录。
- 重启后账户与配置保持不变；仅清理本次测试项目的容器和卷，未部署正式服务。
- 最新镜像拒绝无效 PUID/PGID/UMASK；自定义 UID 12001、GID 12002 的进程身份验证通过，SIGTERM 干净退出（状态码 0）。
- 所有测试凭据与报告均为合成数据，未发送到云端模型。

## 不能误报为已完成的能力

没有 OCR/血检结构化、审核确认、单位标准化、趋势、HealthKit/Health Connect、导出、报告/账户删除或 iPhone 界面。模型配置当前拒绝启用。原文件保存不等于血检已入档，任务状态也不表示识别成功。

解析在有字节/像素/页数限制的进程内运行；当前是个人开发基线，公众版仍需对不可信文档处理、资源隔离和完整安全边界进行后续验证。没有真实血检准确率或医学判断能力的声明。

下一项优先实施 P04：文档服务适配、结构化候选、原文定位与审核版本，同时继续 P00 的真实样本与模型能力验证。
