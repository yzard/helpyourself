## 自动验证

- Rust：46 项测试通过（tests/backend），包括新旧数据库迁移、归属、会话重置、上传和删除重放、报告审核、趋势、健康同步、模型调用、租约与导出。
- `cargo fmt --all --check`、`cargo clippy --locked --all-targets -- -D warnings` 通过。
- Swift 6.2 容器编译 HelpYourselfCore；3 项 Swift Testing 测试通过：嵌套数据/身份、持久批次恢复和路径隔离、服务器地址校验。
- 所有 iPhone Swift 源码由编译器执行语法解析。Linux 不含 SwiftUI/HealthKit SDK，因此这不是完整 iOS build 成功。
- 最新 Docker release 构建成功。`tests/docker/deployment.py` 使用独立项目和随机端口，以 Caddy 测试 CA 验证 HTTPS，运行登录→上传→原件→复核→趋势→完整导出→重启保留→停服复制恢复→报告/账户删除。只清理自己创建的卷；输出位于 build/deployment-check/result.json。
- 测试仅使用合成图片、合成 PDF、假模型结果及临时凭据；没有接触真实健康信息或向云模型发送真实报告。

## 审核中修复的问题

1. 旧报告删除若清理整个 exports/user 目录，会误删之后生成的有效导出：改成事务中枚举当时导出 ID，逐个清理，并增加回归测试。
2. 删除丢失响应后旧上传重试可能复活材料：增加 deleted_uploads 最小标记和事务检查。
3. OCR 晚到写入、过期租约及分析输入变化：提交前检查所有者、有效租约/状态和数据版本；删除后不再发布结果。
4. 报告详情/分析详情多查询可能混用修订：使用读事务取得一致快照；反馈状态检查和插入同事务。
5. 非数据量变动的覆盖更新也会改变导出：更新覆盖或新增连接时使旧导出失效。
6. 分析幂等摘要不应受“当前计算时间”扰动：去掉易变 computed_at，保留来源、算法和 provider 配置指纹；配置变化不误标为原模型结果。
7. iPhone 观察项 ID 与报告 ID 混用、账号删除字段和分析能力字段不匹配：已对照 HTTP 契约修正。
8. iPhone 离线退出不能等待网络：本机先清除，再尽力撤销服务器 token；已删除报告在成功刷新后清除缓存，异步结果检查会话身份。
9. OCR 同页同名同引文的多个印刷行不能静默合并：候选键加入同类行出现次序，保留重试去重和人工版本。

## 外部验收阻塞

- **Apple SDK/设备**：没有 Mac/Xcode、开发签名与连接的 iPhone。完整 App 编译、安装、权限、实际 Watch 明细、断网重启、扫描、分享与可访问性仍待真机记录，不能交付已签名 IPA。
- **真实报告与模型**：没有实际 Function Health PDF/照片和可调用模型配置。尚无逐字段准确率、漏项率、耗时/内存基准；Unlimited-OCR 适配测试仅验证协议路径。
- **临床评审**：来源可追溯、结构符合并不证明疾病假设正确。语义合理性、误报/漏报和公众版条件必须人工评审；所有结果固定为 unverified，默认模型关闭。

以上阻塞需要真实外部资源，继续添加模拟测试无法消除。按批准顺序先通过阶段 A 真机/样本验收，再打开个人分析。临床案例评审框架见 [clinical-review.md](clinical-review.md)。
