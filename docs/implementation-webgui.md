# Web GUI 实施与验收

日期：2026-10-03。范围：由 `backend_api` 提供的浏览客户端，随 API Docker 镜像交付。

## 已批准的边界

- 沿用 iOS 的 Reports、Trends、Health、Insights、Settings 导航与 teal 配色。
- 浏览报告、原件、人工修订、标准化数值与印刷参考范围；所有趋势点能回到来源报告。
- 浏览移动端已同步到数据库的健康明细、平台覆盖与按来源计算的最近 30 天汇总。
- 运行现有血脂预设 AI 分析，读取状态、源快照、发现和就医问题；支持失败重试。预设采用最近 90 个日历日与浏览器时区，模型接口与开关仍归服务器配置。
- 网页不提供报告上传、复核修改、平台连接、健康同步或写入 Apple Health 的入口。导入与平台写入属于移动端；Android 后续实现。

## 实施拆分

1. `src/frontend/`：无外部依赖的 HTML、CSS、浏览器 ES modules，响应式布局，加载/空数据/错误状态，可键盘操作的图表和来源链接。
2. `src/backend_api/webgui.rs`：只挂载根页面与明确列举的 `/assets/` 资源。编译时嵌入二进制，无运行时目录扫描或 SPA 兜底，未知 API 继续返回 JSON 404。
3. 保持已有 Bearer 登录接口；token 仅存在页面内存，刷新后重新登录。401、过期或退出清空界面和会话，导航取消旧请求。原件带认证获取后通过临时 blob URL 展示，关闭即释放。
4. Docker builder 纳入前端源文件，API 二进制携带全部网页资源；不新增前端容器、代理规则或资源挂载。
5. Rust 路由、Node API 客户端回归测试进入构建；浏览器验收使用独立合成账户和数据库。

## 认证与安全契约

网页静态页面公开，个人数据和原件仍由既有 API 的用户隔离与认证保护。网页操作范围是客户端能力，不是新只读账户权限：既有 Bearer 会话沿用现有权限。

不使用 CDN、浏览器业务数据库、cookie、localStorage 或 service worker。CSP 限制脚本、样式和 API 为同源，禁止内联脚本、第三方连接和框架嵌套；返回 no-store 与 nosniff。报告文本和 AI 文本使用 textContent，引用链接限制 HTTP(S)。

## 验收入口

- 前端：`node --test tests/frontend/*.mjs`，并检查各浏览器模块语法。
- 后端：在 `src/backend_api/` 执行格式、Clippy 和现有全部测试。
- 镜像：`./build_docker.sh`；浏览器直接打开现有 Caddy 域名根路径。
- 合成数据验证登录、报告浏览、原件预览、趋势来源、健康覆盖与详情、AI 禁用/排队/成功/失败/过期状态、退出、跨用户不可见、窄屏和键盘操作。
- 真实报告准确性、临床有效性和移动端真机验证沿用原验收关口。
