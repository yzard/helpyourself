# Web GUI 实现与审查

日期：2026-10-03。范围：浏览客户端、API 静态挂载、镜像打包及相关文档和测试。

## 已交付

- `src/frontend/` 提供 Reports、Trends、Health、Insights、Settings；响应式布局、加载/空数据/错误状态、刷新入口和键盘可操作的来源点。
- Reports 展示原始和服务器标准化数值/参考范围、状态、引用页、修订历史、OCR 与输入证据；认证下载后使用临时 blob URL 预览原件，关闭或切换页面释放。
- Trends 按指标分开绘制全历史，可对比第二项；每个点与来源行能回到报告。图表窄屏坐标与标签保持可读，常量序列居中且不重复轴标签。
- Health 仅读取既有同步明细，最近 30 日汇总保留来源、单位、样本数和算法；原始 envelope 分页浏览。没有上传、复核、平台连接、同步或 Apple Health 写入操作。
- Insights 使用现有血脂预设，健康上下文为浏览器时区下最近 90 个日历日；包含能力开关、排队/运行/完成/失败重试/失效显示、快照、证据与就医问题。
- `backend_api` 固定挂载 `/` 和 assets，静态资源编译时嵌入二进制并随 Docker 镜像提供；原有 API 的认证、用户隔离、JSON 404 和持久 worker 保持同一契约。

## 审查后修正

1. 服务器的标准化 `display` 已含单位，客户端直接展示该字符串，避免重复单位。印刷参考范围使用服务器识别的显式/结果列单位归属，不自行推断。
2. 大于浏览器 32 位计时器上限的会话分段检查，避免合法长会话立即过期；401、到期和退出清空页面数据及内存 token。
3. 导航取消旧请求，旧会话迟到的 401 不清除新会话；操作返回前核对导航信号，避免旧页面结果覆盖新页面。
4. 页面只调用白名单内的读取和预设 AI 操作，原件 URL 受控。所有报告与模型文字用 textContent；证据链接只接受 HTTP(S)。CSP 禁止内联脚本、第三方连接和页面嵌套。
5. 页面、API 与下载使用 no-store；没有 cookie、localStorage、业务浏览器数据库、service worker 或外部资源依赖。网页能力边界不声称是新的服务器只读权限。

## 验证

- API Docker build 中 Rust fmt、严格 Clippy、73 个现有/新增测试和 release 编译通过；新增静态 GET/HEAD、响应头、404 与认证测试。
- 11 个 Node 客户端/展示测试通过：禁止导入与修改、同源认证、过期/撤销、迟到 401、服务错误、原件格式、日期范围、计时器上限、引用链接、单位展示及缺失值。
- Chromium 浏览器检查通过：真实独立 Caddy/API 的登录、报告、图片/PDF 原件、修订、趋势来源和键盘、健康汇总/明细、刷新后登录、退出及会话撤销。桌面与 390px 窄屏截图已检查。
- AI UI 的禁用、排队、成功、失败重试和 stale 状态用合成 HTTP 回复验证，并检查模型文本不执行脚本；真实分析快照、模型调用、引用校验和 stale 失效由既有 Rust 测试覆盖。本次没有使用真实用户数据或临床模型结论。
- 同一隔离部署验证 HTTPS 测试 CA、导出、重启持久化、停止后拷贝/恢复、报告及账户删除，临时容器和测试卷已清理。
- 构建脚本语法、网页模块语法、Python Black/isort 与 diff 空白检查通过。

构建日志与浏览器截图位于忽略的 `build/webgui-*` 和 `build/webgui/screenshots/`；部署结果位于 `build/deployment-check/result.json`。实际使用步骤见 [Web GUI 运行手册](../runbooks/webgui.md)。
