# 用户流程与接口契约

## iPhone 信息结构

首版包含档案、趋势、同步状态和设置；分析在阶段 B 启用。档案显示报告与待审核项；趋势选择一个或多个指标；设置提供服务器地址、登录、健康数据连接、导出及删除。每个视图都有加载、空数据、离线、失败和重试状态。

服务器离线时显示缓存及更新时间；原文件仅对已缓存文件提供离线查看。切换账户或退出清理本地私有缓存；待上传材料需明确提示处理，不跨账户发送。

## 上传到确认

1. 选择 PDF 或照片，预览并创建客户端上传 ID；说明目标服务器及管理员配置的处理服务。
2. 上传验证内容类型、大小、页数；加密或损坏 PDF 返回明确可处理错误，不丢弃原输入。
3. 服务端保存文件和任务，返回资源 ID；客户端关闭后服务端继续执行。
4. 按页提取。当前所有 PDF（包括已有文字层的 PDF）都由 API 渲染为 PNG，图片直接或经 HEIC 的 JPEG 副本提交 backend_ocr。同时按页提取并归档 PDF 文本层、词坐标和原始 bbox XML，作为模型的额外证据；空层/失败/超限可见，不凭存在文字层跳过视觉。原始 PDF 完整保留。每页成功或失败独立记录。
5. backend_ocr 从同次推理生成结构化候选，API 在先保存完整回复后进行领域校验；OCR 文本成功不等于结构化成功。
6. 原文与候选并排审核，支持补项、修正、拒绝、部分确认。未完成页和未解析区域明显提示。
7. 确认提交带预期修订号；事务更新当前有效版本。已确认但不能数值比较的项目仍可归档查看。
8. 重复文件返回既有记录或候选关联；修订报告需用户决定替换关系。重跑提取不覆盖人工确认。

报告汇总状态由项目与页面状态派生：处理中、待审核、部分入档、已入档、处理失败。任务成功可以对应“待审核”，不能等同于数据已确认。

## 健康平台同步

1. 在 iPhone 请求所需类型访问并建立同步连接；平台类型适配能力在 P00 真机确认。
2. 按数据类型分页读取变更；本地持久保存批次及候选查询游标。
3. 服务器按批次 ID 和摘要幂等接收，先持久化原始 JSON，再事务发布 SQLite 明细及文件索引；删除事件清理相关原始载荷与文件，完成接收后返回回执。
4. 客户端仅在同一查询页的全部拆分批次获得服务器回执后推进本地游标；若提交后响应丢失，重放同批次获取相同回执。
5. 重装或游标失效时允许重扫，靠来源身份去重；不能把重扫期间未出现的记录自动删除。
6. 按类型显示可观察范围、最后成功时间与失败；打开 App 及手动触发保证路径，后台仅优化时效。

并非所有 HealthKit 类型都使用相同查询方式。序列、关联和删除语义逐适配器验证。读取授权无法直接推断的情况保持未知，而不是误报“用户未授权”。参考 [平台资料](decisions-and-references.md)。

## 趋势与原文

指标查询只返回符合比较规则的有效记录，并显示仍有多少已归档但不可比较的记录。多指标使用分面或独立轴，参考区间随检测点变化；不绘制统一“长寿最佳范围”。点击任何点可查看原始与转换值、审核历史及原报告位置。

## 持久化任务

状态：queued → running → succeeded / retry_wait / failed / canceled。执行器领取租约并续租；启动后回收过期租约，使用输入版本及幂等键避免重做结果。外部模型调用是至少一次语义，不能承诺超时后 provider 没有收费。

网络与临时服务错误有限退避重试；配置错误、无效输入和无法校验的结构化结果进入可见失败状态，不能无限自动重试。手动重试保留尝试历史，配置变更可重试但记录新的配置版本。不自动换 provider。

删除、确认修正与任务完成竞争时，提交前重新检查资源状态和输入修订；过期结果不能覆盖新数据。阶段 B 以确认事务的事件创建分析任务，短时间内同一报告的多次部分确认可合并排队；已运行旧分析标记为过期。

## 接口能力契约

下表概述能力与关键约束；当前路径、HTTP 方法及上限以 [API 契约](api.md) 为准。

| 能力 | 输入重点 | 输出与一致性 |
| --- | --- | --- |
| 登录/撤销 | 凭据或当前会话 | 可撤销身份，无任意 user_id 参数 |
| 上传/查询文件 | 上传 ID、文件、摘要 | 文件 ID、任务 ID、幂等回执 |
| 报告读取/审核 | 资源 ID、期望版本、项目修订 | 新版本、冲突或待审核计数 |
| 重复处理 | 两份报告及关系决定 | 同用户校验、关系版本 |
| 健康同步 | 连接、批次 ID、记录变更 | 原子批次回执、重放一致 |
| 趋势/聚合 | 指标、时段、时区、分页 | 数据、出处、算法版本与覆盖 |
| 任务查询/重试 | 任务 ID | 安全错误码、阶段进度 |
| 导出 | 格式和范围 | 持久任务及鉴权下载 |
| 删除 | 资源范围、期望版本 | 清理状态及最终完成 |
| 分析/反馈（B） | 范围、输入版本或 finding ID | 依据、状态、反馈版本 |

资源列表使用稳定分页；大文件流式传输。错误区分未认证、禁止、版本冲突、无效内容、超限、暂时不可用；日志用请求 ID 关联，不回显原文或密钥。

## 导出与 AI

导出 v3 包含版本化清单、报告与健康修订原件、完整 OCR/解析回复、结构化 JSON、便于使用的 CSV、修订和出处、算法/单位说明。JSON 为无损主格式，CSV 不承担所有复杂载荷。导出所有权校验与原文件相同；生成过程与删除竞争时取消或重新生成，不能通过旧下载暴露已删数据。

分析只读取确认且当前有效的数据快照，记录输入版本、聚合算法与 provider 版本。医学来源由阶段 B 的可核验资料集提供；模型凭空生成的 URL 不作为证据。缺依据时可解释数据但不发布疾病假设。反馈包括未验证、已与医生讨论、后续资料及人工备注，不自动把用户认可当医学验证。
