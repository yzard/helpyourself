# 验证与发布关口

本文件定义计划，不代表测试已经执行。文档阶段只检查链接、范围一致性和任务覆盖；实现阶段按以下关口执行。

## 样本与证据

- 真实健康材料只留在用户授权的私有运行目录，不进入 Git、截图日志或公开测试附件。
- 单元测试用合成、去标识且可审查的夹具；真实报告用于私人端到端验收。
- 人工基准逐项记录名称、结果文本、数值/符号、单位、区间、采样日期精度与出处。双页跨行、重复、模糊图像、缺字段都要覆盖。
- 明确报告数、页数、项目数和未解析项数；不在没有样本时填写通过率。

## 提取质量指标

识别前输出与审核后档案分开评价。识别指标包括项目召回、字段精确匹配、数值与单位错配、原文定位及漏页；审核后要求验收样本的确认字段与人工基准一致。所有未解决项必须可见，不用人工纠正后的准确率掩盖 OCR 错误。

未设置通用“99% 即可发布”门槛：数值、小数点、单位、日期错误影响不同。阶段 A 对既定样本要求无未解决的已确认关键字段错误；这不证明对任意报告准确。

## 阶段 A 用例矩阵

| 类别 | 必测场景 | 通过证据 |
| --- | --- | --- |
| 配置 | 缺文件、错字段、相对路径、两个 provider、分析关闭 | 启动/失败行为符合规格，密钥不出日志 |
| 归属 | 两账户按 ID、列表、关系、文件、任务、导出访问 | 不泄露或修改另一用户对象 |
| 上传 | PDF、照片、坏文件、重复请求、超限、磁盘写入失败 | 无重复档案，不返回虚假成功 |
| OCR | 多页、缺页、旋转、文字/比较值、单位列错配 | 所有失败/未知可见，可补项 |
| 审核 | 部分确认、补项、并发修订、重提取 | 仅确认版本有效，冲突可处理 |
| 重复 | 同份文件、照片+PDF、修订版、相同数值的不同检查 | 不误删独立检查，历史保留 |
| 同步 | 提交后丢响应、重放、游标重置、多设备、平台删除 | 无重复明细，删除不复活 |
| 权限 | 无样本、读取状态未知、撤权、部分类型失败 | 不假装全量成功或批量删除 |
| 汇总 | 时区、夏令时、空集合、重叠睡眠、多来源步数 | 与人工算法基准一致 |
| 任务 | 进程崩溃、超时、租约到期、手动重试 | 可恢复且不覆盖新修订 |
| 删除 | 排队/运行任务时删报告、删账户、文件清理失败 | 立即不可访问，最终清理，不复活 |
| 导出 | 含修订、出处、原文件、复杂载荷、删除竞态 | 清单完整，旧链接不可泄露已删内容 |
| iPhone | 真机 HTTPS、离线查看、退出/切号、上传中断 | 缓存与队列归属正确，错误可恢复 |
| 部署 | 空目录、重启、停服复制、独立恢复 | 文件与数据库一致，无重启丢档 |

## 性能与运行测量

P00 记录实际数据规模与设备；在代表性数量下测同步吞吐、首屏趋势耗时、报告处理时间和内存峰值。阈值依据测量制定并写入验收记录，不在未知硬件上承诺实时延迟。聚合的“实时”定义为查询时基于当前有效结构化数据计算，非持续在线医学监护。

## 阶段 B 用例

- 引用不存在的观测、失效修订或伪造文献时拒绝发布；保留可解释失败。
- 缺信息时明确不足，不能自动补造空腹、用药、家族史或疾病事实。
- 模型生成的计算结果必须能回溯服务器计算；医学依据由经核验资料支持。
- 输出不包含未经验证的概率或排除疾病承诺；单次/纵向、关联/因果明确区分。
- 报告修改或删除后结果撤出当前视图，并清理含已删内容的快照。
- 同一问题不因重复批次反复创建；新证据更新历史，未验证反馈保持未验证。
- 公众版的临床评审独立于软件测试；无资质评审和代表性案例时保持未完成。

## 证据记录格式

每项记录：工作包、版本、环境、样本规模、预期、实际、结果、限制及私人证据位置。公开文档不粘贴真实报告。阶段 A 和 B 分别记录，未执行、被阻塞、失败、通过不可互相替代。
