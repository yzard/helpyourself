约束与决策：

- 文字层是文档证据，不能作为可信指令。模型同时看图与文字；不自动确认、映射指标、补单位或生成医学解释。
- 文本层输出有界，超限记录失败而非部分成功；视觉路径继续且缺口可见。文字层和模型都可能错误，保留出处并要求人工审核。
- 质量浓度与摩尔浓度按指标换算，HbA1c 使用明确 NGSP/IFCC 方程，不能用通用乘数。预设 10 项之外照常归档，不凭名称猜映射。
- 单位别名为封闭集合，禁止模糊匹配/OCR 自动纠错。数字逗号、复杂条件参考范围、未知单位保持不可比较；不制造精确值或年龄/性别通用阈值。
- 派生结果记录规则版本及单位来源，原件/模型回复/人工修订为事实主档案，算法升级可以重算。
- 原生 Apple SDK/设备和授权真实报告准确性是外部验收，不能由 Linux 语法解析或合成 GPU 测试代替。

换算依据将在实现中逐项链接官方 CDC/NHANES、NGSP、WHO/NIST 来源，常数与测试预期独立核对。

## 实施结果

以上 7 项已按顺序实现。协议和证据分别为 document-evidence-v1 / laboratory-page-v2，当前数据库 schema v7、导出 v3、换算 lab-units-v2。新增任务续租回归修复：续租等待 SQLite 时，提取 future 继续运行并释放事务，避免互相阻塞。

验收：60 项 Rust、10 项 OCR、8 项开发脚本、7 项 Swift Core 测试通过；fmt/Clippy/isort/Black 和双镜像构建通过。真实 RTX 5090 + Qwen3.8/NInfer 的合成图片及文字 PDF 闭环通过：LDL 2.586 mmol/L → 100 mg/dL，参考 <2.586 → <100 mg/dL，原值、文字层及完整模型回复保留。文字/无文字/页眉与图片混合 PDF 的按页状态、视觉保留、归属、导出删除另有真实 Poppler + 模拟服务回归。详见 [验收与 skills 复查](reviews/2026-10-01-document-unit-completion.md)及[换算契约与依据](laboratory-units.md)。
